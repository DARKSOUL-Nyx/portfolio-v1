## The Mission
Coordinating multiple drones without a central server is a classic distributed systems problem. In this project, I implemented a **Boid Flocking Algorithm** modified for latency-constrained hardware.

### Key Architecture
* **Edge Nodes**: Raspberry Pi 5 w/ Hailo-8 AI Accelerator.
* **Comms**: LoRaWAN mesh network (915MHz).
* **Protocol**: Custom UDP-based gossip protocol for state sharing.
